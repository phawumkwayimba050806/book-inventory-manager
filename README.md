# Book Inventory Manager

A Flet desktop app for managing a bookstore's inventory.

## Features
- Add, edit and delete books
- Search by title or author
- Statistics page with totals, average rating and low-stock warnings
- Data saved automatically to books.json
- Input validation with friendly error messages

## How to run
1. Install Flet: `python -m pip install flet`
2. Run the app: `python main.py`

## Built with
Python, Flet, OOP (Book and Inventory classes) and JSON file storage.
